```text

├── week-08/                   # 第 8 周  多轮对话与记忆机制
├── week-09/                   # 第 9 周  函数调用：给 AI 装上「工具箱」
├── week-10/                   # 第 10 周  AI 生成图表与可视化报告

├── week-12/                   # 第 12 周  人机交互设计：让用户愿意用
├── week-13/                   # 第 13 周  AI 应用的测试与错误处理
├── week-14/                   # 第 14 周  项目优化与性能调优
├── week-15/                   # 第 15 周  期末项目打磨与演示准备
├── week-16/                   # 第 16 周  期末答辩与学习总结
│
├── final-project/             # 期末综合项目
│   ├── README.md              # 项目说明与运行方式
│   ├── src/                   # 源代码
│   └── report/                # 结课报告
│
└── notes/                     # 每周学习笔记与踩坑记录
    ├── cheatsheet.md          # 常用命令速查表
    └── pitfalls.md            # 我踩过的坑
```

每周目录内含 `README.md`（本周目标与实验报告），Git 会自动记录每次提交的时间，天然形成**不可篡改的学习时间线**。
