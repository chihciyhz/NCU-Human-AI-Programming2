# 常用命令速查表

## 每次上机三步走

``ash
git add .
git commit -m "week-01: 说明这次改了什么"
git push
``

## 常用查看命令

| 命令 | 作用 |
| :--- | :--- |
| `git status` | 看看哪些文件改动了 |
| `git log --oneline` | 看看历史提交记录 |
| `git diff` | 看看具体改了哪些字 |
| `git restore <文件>` | 撤销还没提交的改动 |
| `git pull` | 把云端的更新拉回本地 |

## 温馨提示

写代码前先 `git pull`，写完机房再 `git push`，养成习惯就不会打架啦。
